# ATLAS Live Commerce & Investor Studio

ATLAS control room for live product presentation, approval workflows, teleprompter content, commerce calls-to-action and lead capture.

## Scope

- TikTok LIVE readiness/status surface
- Product and service presentation queue
- Human approval before publication
- Teleprompter and product-background workflow
- Commerce / donation / investor-interest routing kept separate
- OBS / virtual-camera production workflow
- Analytics-ready event model

## Safety and compliance boundaries

- No TikTok credential is stored in source code.
- TikTok publishing remains disabled until an approved TikTok developer integration and account authorization are configured.
- Investment-interest capture is informational only. It does not accept securities investments or promise returns.
- Direct sales, donations and investment-interest flows must remain distinct.
