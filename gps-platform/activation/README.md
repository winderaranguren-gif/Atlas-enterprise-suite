# ATLAS GPS 4D — Production Activation Control Pack

This directory converts the remaining external dependencies into explicit, auditable activation work. It does not pretend that a third party approval, paid cloud account, data license, or real-world safety certification can be generated by source code.

## Activation tracks

1. **Planetary infrastructure** — deploy the Kubernetes production topology, provision durable storage, configure backups, observability, multi-region failover and recovery drills.
2. **Planet map import** — import OpenStreetMap planet or regional extracts, build tiles/search/routing indexes, record source dates and run data-integrity checks.
3. **Domain, DNS and TLS** — use the Cloudflare provisioning script with founder-controlled credentials; enforce DNSSEC, proxied records and strict TLS.
4. **Live-data feeds** — place authorized provider endpoints and tokens in the secret store, validate freshness, coverage and outage behavior.
5. **Maritime and aviation** — ingest official/public-authority products where terms permit; keep marine and aviation guidance clearly separated from certified ECDIS/avionics use unless independently certified.
6. **CarPlay** — submit the prepared navigation entitlement package from the ATLAS Apple Developer account and sign the required addendum.
7. **Android for Cars** — complete the car-quality test matrix, produce signed app bundles and submit the car release through Google Play.
8. **Computer vision** — train, evaluate, sign and independently validate lane, sign, vehicle, pedestrian and obstacle models. Unvalidated models remain advisory-only.
9. **Global field validation** — execute controlled tests with trained personnel, local legal review, safety drivers, incident logging and stop-work authority.

## Files

- `../data/official-sources.json` — controlled registry of official/public-authority data sources.
- `../approvals/carplay-entitlement-package.md` — completed application draft and evidence checklist.
- `../approvals/android-for-cars-release-package.md` — release and quality-review package.

- `../../scripts/gps-production-readiness.js` — deterministic readiness report.

## Release rule

ATLAS GPS 4D may be called **production-ready for a specific territory and mode** only when every required item for that territory and mode has verifiable evidence, current data, passing automated tests, passing field tests and an authorized release signature. Planetary availability is the aggregate of independently approved territories; it is not a single unchecked switch.
