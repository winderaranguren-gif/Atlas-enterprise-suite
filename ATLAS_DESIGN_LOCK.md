# ATLAS Command Center — Design Lock DL-1.0

Approved product direction: 2026-08-10.

This file establishes the ATLAS Command Center approved visual direction as the canonical implementation reference for web, PWA, mobile surface and desktop surface.

## Required visual invariants
- ATLAS branded top bar with global search and Esther/Admin profile surface.
- Fixed left navigation on desktop; compact bottom navigation on mobile/app surfaces.
- Dark futuristic 4D digital-glass aesthetic with depth, neon cyan/purple/blue accents and atmospheric sky/city visual stage.
- Command Center as the default landing view.
- KPI cards, module-family cards, live status panel, reflection panel, quick actions, activity/tasks/module-usage panels.
- ATLAS Repertoire accessible directly from the main navigation.
- Update Fabric visible as an active platform capability.
- Responsive layout must not horizontally overflow the viewport on iPhone/mobile.
- Web and app surfaces share one design system and one product shell.

## Implementation rule
An approved visual may not be replaced with a materially different shell during integration. Any intentional redesign requires a new Design Lock version and explicit approval before promotion to production.
