## 0. Structural doctrine

ATLAS is one intelligent ecosystem. Every new capability must declare:

1. **Root** — principle or invariant that gives it legitimacy.
2. **Trunk** — shared ATLAS Core services it depends on.
3. **Primary branch** — domain family where it belongs.
4. **Sub-branch** — concrete functional system.
5. **Leaves** — user-visible functions and workflows.
6. **Fruit** — measurable output that helps a person, organization, community or institution.
7. **Evidence** — code, API, migration, validated artifact, release gate, test, proposal or research dossier that proves the stated maturity.

No capability may become a new disconnected ATLAS product merely because it has a separate screen. Shared identity, security, tenant isolation, auditability, global context and navigation remain common roots/trunk services.

### Maturity taxonomy

- **ROOT** — constitutional principle; not a product.
- **TRUNK** — shared production foundation.
- **BRANCH** — product/domain family.
- **WORKING FRUIT** — implemented and testable in ATLAS source or as a verified artifact.
- **RIPE FRUIT** — working fruit with explicit release/verification evidence for its intended environment.
- **GREEN FRUIT** — functional prototype/workspace with a known missing production dependency.
- **SEED** — approved concept/research direction not yet represented as production functionality.
- **PARTNER-BOUND** — function that requires a licensed/authorized external provider for regulated execution.
- **ARCHIVE** — historical evidence retained for continuity, not current architecture.

# PART VII — RULE FOR ALL FUTURE DEVELOPMENT

Before creating a new module, route, repository, database table or visual concept, ATLAS must answer:

1. Which root principle authorizes it?
2. Which trunk services must it reuse?
3. Which existing branch owns it?
4. Is a new branch actually necessary?
5. What authoritative system of record owns its data?
6. What permissions and audit evidence are required?
7. What regulated execution boundary applies?
8. What is the smallest useful fruit the user receives?
9. What test proves that fruit works?
10. What evidence permits ATLAS to call it working, ready or LIVE?

If those ten questions are not answered, the item remains a **seed**, not a production fruit.
