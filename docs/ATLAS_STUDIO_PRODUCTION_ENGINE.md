# ATLAS Studio Production Engine

ATLAS Studio Production Engine is a clean-room media workflow that consolidates the production capabilities ATLAS previously had to reach through separate creative applications.

## Product goal

Provide one ATLAS-owned workflow for:

1. ingesting a source video;
2. inspecting metadata;
3. selecting a strong visual window;
4. trimming and reframing;
5. applying deterministic visual treatment;
6. importing or creating captions;
7. applying browser-native speech cleanup;
8. rendering a real processed output;
9. attaching optional model runtimes for transcription, digital twins, lip sync, enhancement and identity-preserving video restyling.

The implementation recreates capability classes and workflow patterns. It does not copy third-party source code, private models, branding or proprietary assets.

## Capability mapping

| Capability class | ATLAS implementation | Execution state |
| --- | --- | --- |
| Media ingest and edit workbench | Local file import, video preview, metadata, trim, canvas rendering | Implemented locally |
| Quick/highlight cut | Motion-scored frame sampling and best-window suggestion | Implemented locally |
| Transcript/caption workflow | SRT import, manual cues, preview and burn-in | Implemented locally |
| Vertical social formatting | 9:16 crop, contain, or blurred-background layout | Implemented locally |
| Look/color treatment | Brightness, contrast and saturation render controls | Implemented locally |
| Speech cleanup | 80 Hz high-pass + dynamics compression | Implemented locally |
| Export | Canvas CaptureStream + MediaRecorder with MIME probing | Implemented locally when browser supports required APIs |
| AI transcription | `ATLAS_TRANSCRIBE_ENDPOINT` | Runtime adapter slot |
| Digital twin/avatar | `ATLAS_AVATAR_ENDPOINT` | Runtime adapter slot, consent required before use |
| Lip sync | `ATLAS_LIPSYNC_ENDPOINT` | Runtime adapter slot |
| AI enhancement / super-resolution | `ATLAS_ENHANCE_ENDPOINT` | Runtime adapter slot |
| Generative video restyle | `ATLAS_VIDEO_EDIT_ENDPOINT` | Runtime adapter slot |

## Routes

- `/studio/production` — production UI.
- `/api/studio/production/health` — service health and configured runtime count.
- `/api/studio/production/capabilities` — local and model-backed capability contract.
- `/api/studio/production/runtime-status` — configuration state without exposing credentials.

The shared router gives the production handler priority over the existing `/studio/*` shell, then falls back to the original Creator Studio.

## Privacy model

The browser-native pipeline is local-first. A selected video is loaded with an object URL and is not uploaded by default. Model-backed capabilities are not marked as connected unless their corresponding runtime endpoint exists in the Worker environment.

Runtime endpoints must not be exposed as unauthenticated public proxies. Before a model action is added, it must inherit ATLAS session/RBAC enforcement, tenant scoping, audit logging and explicit consent where identity or voice data is processed.

## Digital-twin consent

Identity cloning, avatar creation and voice cloning require explicit user consent. ATLAS should keep a consent record containing at minimum:

- tenant and user identifier;
- source asset identifier;
- consent timestamp;
- allowed purposes;
- retention policy;
- revocation state;
- audit actor.

No UI should imply that a private avatar or cloned voice exists before training and consent actually complete.

## Browser export behavior

The production UI probes MediaRecorder formats in this order where supported:

1. MP4 / H.264 + AAC;
2. MP4 browser default;
3. WebM VP9 + Opus;
4. WebM VP8 + Opus;
5. WebM browser default.

A render uses the selected trim, aspect ratio, reframe mode, visual treatment and caption cues. Output is generated by the browser, not represented as completed until a Blob is produced.

## Smart Cut limitations

Smart Cut is intentionally described as visual-motion analysis. It samples decoded frames, converts them to luminance vectors, measures frame-to-frame difference and selects the target-duration window with the strongest aggregate motion score.

It does not claim to understand speech meaning, emotion, retention, virality or audience response. Those capabilities require authorized model runtimes and real analytics data.
