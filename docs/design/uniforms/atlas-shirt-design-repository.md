# ATLAS Shirt Design Repository

Owner: Winder Aranguren
Project: ATLAS uniform system for shirts, future employee uniforms, and module-based apparel designs.

## Current request
Create a professional visual system with 56 total outputs:

- 50 individual image outputs: 10 shirt models x 5 variations each.
- 5 grouped compositions showing the shirt models arranged in different catalog formats.
- 1 master catalog poster with all options.

## Face and identity rule
Use Winder's confirmed reference photo as the identity anchor. Preserve real facial features, tone, apparent age, proportions, and natural expression. Improve grooming, lighting, clothing presentation, posture, and professional finish only. Do not change the face into another person.

## Shirt model structure
1. Polo clásico
2. Polo profesional / operations
3. Camisa Oxford
4. Camisa slim fit
5. Camisa linen
6. Camisa cubana
7. Camisa estampada
8. Camisa casual
9. Camisa ejecutiva
10. Camisa premium

## Required output organization
Each model must have five variants:

- Variant A: executive / dark professional
- Variant B: modern / blue or navy
- Variant C: light premium / white or light blue
- Variant D: functional / field-ready
- Variant E: brand accent color / ATLAS module color

## Grouped compositions
1. Executive catalog grid
2. Module-based uniform grid
3. Field / operations grid
4. Premium client-facing grid
5. Social media promotional grid
