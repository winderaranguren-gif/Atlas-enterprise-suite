## Completion rule

A branch is **Structured** only when it has:

1. a human-readable branch dossier;
2. a machine-readable genealogy registry;
3. explicit roots and trunk dependencies;
4. authoritative object ownership;
5. maturity classifications;
6. fruit chains and invariants;
7. next-fruit sequence;
8. validation coverage in `validate:genealogy`.

The status in this file describes **genealogical structuring**, not production deployment maturity.
