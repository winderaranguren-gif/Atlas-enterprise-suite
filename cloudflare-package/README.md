# ATLAS Cloudflare Package

Paquete separado para despliegue y operación de ATLAS en Cloudflare.

## Estructura
- `app/` — sitio listo para publicar.
- `assets/photos/` — fotografías organizadas por módulo.
- `assets/icons/` — iconografía.
- `assets/brand/` — logos y marca.
- `config/` — configuración Cloudflare.
- `docs/` — documentación de despliegue.

## Regla
Este paquete no reemplaza el repositorio principal. Sirve como capa de publicación limpia para Cloudflare.
